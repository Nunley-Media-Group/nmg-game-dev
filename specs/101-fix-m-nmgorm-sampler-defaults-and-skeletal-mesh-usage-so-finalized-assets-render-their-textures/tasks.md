## Implementation Tasks

### T001: Set typed sampler defaults and skeletal-mesh usage in the builder

**File(s)**: `scripts/unreal/build_master_material.py`
**Type**: Modify
**Depends**: none
**Acceptance**:
- `_sampler()` takes a default texture path, loads it with `unreal.EditorAssetLibrary.load_asset`, raises `RuntimeError` naming the path when it is not an `unreal.Texture`, and sets the node's `texture` property (FR1).
- `_build()` passes `/Engine/EngineResources/DefaultTexture` for `BaseColor`, `/Engine/EngineMaterials/DefaultNormal` for `Normal`, and `/Engine/EngineMaterials/DefaultDiffuse_TC_Masks` for `ORM` (AC1, FR1).
- `_build()` sets `used_with_skeletal_mesh` to `True` on the material before `recompile_material` (AC2, FR2).
- Parameter names, sampler types, connections (BaseColor RGB → MP_BASE_COLOR, Normal RGB → MP_NORMAL, ORM R/G/B → MP_AMBIENT_OCCLUSION/MP_ROUGHNESS/MP_METALLIC), the load-and-`_clear()` path for an existing asset, the `NMG_RESULT` line, and exit codes are unchanged (AC3).
- The file passes `ruff check`, `ruff format --check`, and `mypy`.

### T002: Rebuild the shipped M_NmgORM asset

**File(s)**: `plugins/nmg-game-dev-ue-plugin/Content/Materials/M_NmgORM.uasset`, `CHANGELOG.md`
**Type**: Modify
**Depends**: T001
**Acceptance**:
- `M_NmgORM.uasset` is regenerated by running `uv run --group dev python scripts/unreal/build_master_material.py` against a UE 5.8 editor started with `UE_PROJECT=fixtures/dogfood.uproject scripts/start-unreal-mcp.sh`, and the script exits 0 (FR3).
- The committed asset's bytes contain `/Engine/EngineMaterials/DefaultNormal`, `/Engine/EngineMaterials/DefaultDiffuse_TC_Masks`, and `bUsedWithSkeletalMesh` (AC1, AC2).
- `CHANGELOG.md` `[Unreleased]` has a Fixed bullet describing the master material fix that ends with `(#101)`.

### T003: Add regression coverage for the builder and the shipped asset

**File(s)**: `tests/unit/test_build_master_material.py`, `tests/bdd/features/master_material.feature`, `tests/bdd/test_master_material_bdd.py`
**Type**: Create
**Depends**: T001, T002
**Acceptance**:
- Unit tests import `_MATERIAL_CODE` from `scripts/unreal/build_master_material.py` and assert that it sets `texture` on the samplers, names the three default texture paths paired with their parameters, and sets `used_with_skeletal_mesh` to `True` before `recompile_material` (AC1, AC2).
- A unit test asserts that the committed `M_NmgORM.uasset` bytes contain `/Engine/EngineMaterials/DefaultNormal`, `/Engine/EngineMaterials/DefaultDiffuse_TC_Masks`, and `bUsedWithSkeletalMesh` (AC1, AC2, FR3).
- A unit test asserts that the code keeps the `BaseColor`, `Normal`, and `ORM` parameter names, the five channel connections, and the existing-asset `load_asset` + `_clear` path with no delete or recreate of `M_NmgORM` (AC3).
- `tests/bdd/features/master_material.feature` holds SCN001–SCN003, and `tests/bdd/test_master_material_bdd.py` binds them. `pytest tests/unit/test_build_master_material.py tests/bdd/test_master_material_bdd.py` passes, and the sampler-default and skeletal-usage assertions fail against the pre-fix builder.
