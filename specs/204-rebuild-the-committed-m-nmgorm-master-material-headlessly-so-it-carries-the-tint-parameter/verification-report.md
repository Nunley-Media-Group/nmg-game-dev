## Executive Summary

`scripts/unreal/build_master_material.py` gains a `--headless` mode, mutually exclusive with `--url`. It builds `DogfoodEditor` with `Build.sh`, writes the unchanged `_MATERIAL_CODE` to a temporary script, and runs it in a separate `UnrealEditor-Cmd` process on `fixtures/dogfood.uproject` with the MCP plugins disabled. It never constructs `UnrealMcpClient`. The committed `M_NmgORM.uasset` was regenerated by that mode and now carries `Tint`, `BaseColor`, `Normal` and `ORM` name-table entries, along with its unchanged package path. All 11 registered validations have results: 10 applicable required validations passed, and `gate-ship-smoke` does not apply to this change.

This is a re-verification after deliver's base reconciliation merged `origin/main` (`1293c00`, #218 and #219) into the branch as `5eb369c`. That merge changed none of this issue's files: `scripts/unreal/`, the two test modules, the feature file and `M_NmgORM.uasset` are identical to the previously verified head `e4f08b7`. The merged-in changes that mention `M_NmgORM` (`src/nmg_game_dev/unreal/import_asset.py`, `docs/asset-contract.md`, `skills/finalize-asset/SKILL.md`, `tests/unit/fake_unreal.py`) only reference the master material's package path, which this issue keeps. The full registered gate was rerun at the new head.
